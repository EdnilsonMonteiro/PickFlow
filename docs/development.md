# For those who want to work on the code

The code map and working rules are in [CLAUDE.md](../CLAUDE.md) (in Portuguese: it is the maintainer's working guide).

```
pip install -r requirements-dev.txt
python -m pytest -q
```

The tests use a fake ComfyUI (`tests/fake_comfy.py`) with the **real** (trimmed) `object_info` of a ComfyUI running Qwen-Image 2.1
(`tests/object_info.json`, generated by `tests/make_object_info.py`), a test Clef and a fake HTTP Clef server.
They prove the routing logic, the conversion to the API format (subgraphs included), the `defaults/` + `custom/` layers
and the full flow, but they **do not replace** the *Check workflows* button on your real ComfyUI, nor do they test the Clef with the real weights.
`tests/test_clef_server.py` runs `clef_server/` end to end with a fake model, and one of its tests talks to it over real HTTP.

The word list that the `test_defaults_ship_no_personal_or_nsfw_text` test blocks lives in the git-ignored `custom/blocklist.txt` (one regex per
line; `tests/privacy.py` reads it). Without that file, the test only blocks `nsfw`. Keep your own list on the machine where you publish.

**Interface translation.** The source text is Portuguese (`web/app.js`, server messages, names in `defaults/`);
`web/i18n.js` translates what shows on screen using the `web/locales/en.json` catalog (`strings` for fixed text, `templates`
with `{}` for the variable parts). Editable fields and anything marked `translate="no"` (the user's request) are not
touched. New interface text needs a line in the catalog: `python tests/uitexts.py` lists what is missing and the
`test_catalog_covers_every_interface_text` test fails otherwise.

`python tests/demo_server.py` starts the interface with fake data at <http://127.0.0.1:7861> (with `DEMO_ADDON=1`, already with an addon created from the template; with `DEMO_SPLAT=path/file.spz`, the 3D step returns that real splat). `DEMO_SETUP=1` simulates a brand-new ComfyUI (no nodes, LoRAs or models) and slow downloads, to see the assistant; `DEMO_NO_COMFY=1` a ComfyUI that does not answer; `DEMO_MODELS=1` a second image model (to see the chat's *Model* selector).
